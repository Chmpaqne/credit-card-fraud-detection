# Credit Card Fraud Detection (Machine Learning with Google Colab)

This repository contains a complete machine learning workflow for **Credit Card Fraud Detection** using the publicly available `creditcard.csv` dataset from Kaggle.  
The project was implemented entirely in **Google Colab** and demonstrates:

- Data loading & preprocessing  
- Feature scaling  
- Class imbalance handling (Undersampling + SMOTE Oversampling)  
- Training ML models  
- Evaluating metrics beyond accuracy (Precision, Recall, F1)  
- Saving and loading a trained model  
- Predicting fraud on new input  

---

## 📊 Dataset Information

- **File:** `creditcard.csv`  
- **Source:** https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud  
- **Rows:** 284,807  
- **Features:** 30 anonymized PCA components + Time + Amount  
- **Target:** `Class`  
  - `0` = normal transaction  
  - `1` = fraudulent transaction  

⚠ **Dataset is NOT included in this repository.**  
Download it manually from Kaggle and upload to Google Colab before running.
